## فارسی

**خلاصه: هیچ داده‌ای جمع‌آوری نمی‌شود.**

۱. **ذخیره‌سازی داده‌ها**
تمام کانفیگ‌ها، تنظیمات و ترجیح‌های شما فقط در حافظه‌ی محلی دستگاه (localStorage) ذخیره می‌شود. این داده‌ها به هیچ سروری ارسال نمی‌شوند و برای توسعه‌دهنده قابل دسترسی نیستند.

۲. **دوربین**
دسترسی به دوربین فقط برای اسکن کد QR استفاده می‌شود. تصویر دوربین روی دستگاه پردازش می‌شود و هیچ فریمی ذخیره یا ارسال نمی‌شود.

۳. **اتصال شبکه**
اپ برای تست DNS دامنه‌ی سرور، درخواست DNS-over-HTTPS به سرویس‌های عمومی Cloudflare (`cloudflare-dns.com`) یا Google (`dns.google`) می‌فرستد. در این درخواست فقط نام دامنه‌ی سرور شما ارسال می‌شود. اگر این قابلیت را اجرا نکنید، هیچ درخواستی ارسال نمی‌شود.

۴. **عدم جمع‌آوری داده**
اپ هیچ‌گونه تحلیل، تبلیغات، ردیابی، شناسه‌ی تبلیغاتی، گزارش خطا یا حساب کاربری ندارد.

۵. **پشتیبان‌گیری**
فایل پشتیبان JSON فقط زمانی ساخته می‌شود که خودتان دکمه‌ی پشتیبان‌گیری را بزنید و در محل انتخابی شما ذخیره می‌شود.

۶. **کودکان**
اپ برای همه‌ی سنین مناسب است و هیچ داده‌ای از هیچ کاربری (از جمله کودکان) جمع نمی‌کند.

۷. **تغییرات**
در صورت تغییر این سیاست، نسخه‌ی جدید در همین صفحه منتشر می‌شود.

۸. **تماس**
کانال تلگرام: https://t.me/vodiwalkervpn03

## English

**Summary: no data is collected.**

1. **Storage** — All configs and preferences are stored locally on your device (localStorage). Nothing is uploaded, and the developer cannot access it.

2. **Camera** — Camera access is used only to scan QR codes. Frames are processed on-device and are never stored or transmitted.

3. **Network** — To run a DNS test, the app sends a DNS-over-HTTPS query to Cloudflare (`cloudflare-dns.com`) or Google (`dns.google`) containing only the server hostname you asked to resolve. No request is sent unless you trigger the test.

4. **No collection** — The app contains no analytics, ads, tracking, advertising ID, crash reporting or user accounts.

5. **Backups** — A JSON backup is created only when you tap the backup button, and it is saved wherever you choose.

6. **Children** — The app is suitable for all ages and collects no data from any user.

7. **Changes** — Any change to this policy will be published on this page.
